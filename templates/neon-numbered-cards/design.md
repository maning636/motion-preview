# 霓虹编号双卡

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：暗夜霓虹（荧光绿口播包装族）——近黑蓝底 `#0A0D12`，荧光绿 `#10B981` 主色 + `#34D399` 发光高亮做描边/编号/英文小字标签与外发光，白色粗体中文，红叉 `#EF4444`（语义红，否定专用）。
- 主色由 `accentColor`（color 变量，默认 `#10B981`）驱动：JS 解析后重写 `--acc` 系列 CSS 变量（含各透明度衍生值）；自定义主色时发光高亮自动向白色混合 35% 推导，默认主色固定对应 `#34D399`。
- 字体：标题/编号/卡片标题 = MiSans SemiBold；灰色小字 = MEBHeiHeiTi。
- 动画：递进构建——标题淡入上移 → 卡01 左滑入（内部 stagger）→ 卡02 右滑入 → 卡01 图标叠红叉弹入 → 定格。
- 图标为模板内置 SVG 线性图标（卡1 机器人脸 / 卡2 上升柱状图），无图片素材槽。
