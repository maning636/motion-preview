# API 调用 Mock 视觉规范

## 方向

左右分栏展示 API 请求与响应 JSON，适合演示 REST/JSON 接口调用。

## Palette

- Background: `#12100E`
- Foreground: `#F4EFE7`
- Accent: `#00FF00`
- Panel background: `rgba(244,239,231,0.04)`
- Border: `rgba(244,239,231,0.12)`
- Code string: `#A8C9BF`
- Code key: `#F4EFE7`

## Typography

- 标题：64px，700
- 方法标签：18px，800
- JSON：18px，monospace

## Layout

- 标题区 + 左右两栏
- 左侧 Request，右侧 Response
- 每栏顶部显示 method 与 endpoint

## Motion

- 标题入场
- 左右面板依次滑入
- 代码行打字机式出现
- 结束前淡出

## Avoid

- 不使用真实敏感数据
- 保持代码可读
