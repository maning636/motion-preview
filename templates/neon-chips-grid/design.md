# 霓虹功能chips网格

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 系列：荧光绿口播包装族（暗底）。近黑蓝底 `#0A0D12`，卡片 `#12161C`，主色 `#10B981`，发光高亮 `#34D399`，浅色点缀 `#A7F3D0`，灰色辅助 `#9CA3AF`，白色粗体中文。禁用琥珀橙；语义红 `#EF4444` 仅错误场景，本模板未用。
- 版式：内容列整体居中、内部左对齐——英文小标签（主色、全大写、加字距、前置短横线）→ 中文大标题（titleAccent 词在 titleCn 内命中即绿色高亮）→ 灰色副标题 → chips 区（1px 绿描边圆角小卡 + 外发光，图标+文字，可见 chips 分两行，上行 ceil(n/2) 个，留空的 chip 变量自动隐藏）→ 绿色圆角大框（SVG rect 描边 dashoffset 画出，收拢圈住 chips）→ 底部灰色说明字。
- 字体：英文标签/大标题/chip 文字 = MiSans SemiBold；副标题/说明字 = MEBHeiHeiTi（@font-face 带 font-weight: 100 1000 防合成加粗实心块）。
- 图标：模板内置 7 枚内联 SVG 线性图标（打卡/记账/日程/待办/新闻/选题/复盘），按 chip 序号分配，`#34D399` 描边 + drop-shadow 发光，无图片素材槽。
- 动画（约 3.1s 动效段）：标题组三段递进淡入上移 → chips 逐个 back.out 弹入 stagger 0.11s → 大框描边 0.9s 收拢画出 → 说明字淡入 → 定格。
