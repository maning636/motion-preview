# page-audience-trio · 黑横幅+三受众卡整页

纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 VOL/栏目 + 右页码 mono），其下墨黑横幅（白字 76px 大标题 + 右侧 mono 角标，12px 荧光绿硬偏移投影）expo.out 落下；下方三张受众卡（谁该看 / 谁慎用 / 谁绕道：mono 标签胶囊 + 两行说明 + 卡底荧光绿进度条）以 rotateX -62° 逐张翻亮点名、绿条 stagger 扫满，荧光绿署名条推入，收尾三卡 ±7px 呼吸浮动定格。

- 变量: vol, pageno, title, cards（标签|说明，分号分隔 3 条）, accent, duration
- 字体: MEBHeiHeiTi + MiSans SemiBold（本地硬链接）
- 动效: 动效段 0-3.0s，之后呼吸浮动定格，无收尾 fade-out
