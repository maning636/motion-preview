# 霓虹包名标签chip组

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：荧光绿口播包装族——近黑蓝底 `#0A0D12`，chip 填充 `#12161C`；主色 `#10B981` 描边 + 外发光，发光高亮 `#34D399`，辅助灰 `#9CA3AF`。
- 布局：左上区域纵向排列——小 tag chip（闪光星图标 + 文字，绿描边深色底）→ 大 chip（立方体线框图标 + 包名，绿描边发光深色底，圆角 18px）→ 一行灰色小字；右侧一个简化卡片轮廓（绿描边空框 + 短横线点缀）作占位装饰。
- 字体：tag 文字 = MiSans SemiBold；包名与灰色小字 = MEBHeiHeiTi。仅这两款字体，无系统回退。
- 动画：tag 弹入（back.out）→ 大 chip 左滑入 → 小字淡入 → 右框描边画出（pathLength + stroke-dashoffset）→ 定格。禁用琥珀橙，无橙色元素。
- 图标为模板内置 SVG（闪光星 / 立方体线框），无图片素材槽。
