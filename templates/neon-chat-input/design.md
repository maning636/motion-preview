# 对话输入框打字卡

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：荧光绿口播包装族——近黑蓝底 `#0A0D12`，输入框填充 `#12161C`，胶囊圆角 66px；主色 `#10B981`，发光高亮 `#34D399`，辅助灰 `#9CA3AF`。禁用琥珀橙，无橙色元素。
- 布局：顶部标题组（绿色英文小标签全大写加字距 + 白色中文标题，titleAccent 子串染绿带下划线光条）→ 中央宽胶囊输入框（1px 绿描边 + 外发光，右侧绿色圆形发送按钮含白色 ↑ 箭头）→ 框下绿色状态行（◦ 前缀）。
- 字体：英文标签/中文标题/输入文字 = MiSans SemiBold；状态行 = MEBHeiHeiTi。全系列仅此两款字体，硬链接自 templates 根目录。
- 系列签名动作：promptText 逐字打字（拆字 span + GSAP 0.06s/字 stagger，空格用 NBSP），绿色方块光标在文档流中跟随（insertBefore 移动，免测量、不受字体加载时机影响），打完闪烁两轮后隐藏。
- 动画节奏：标题组淡入 → 输入框升入 → 逐字打字 → 发送按钮 0.3s 发光脉冲 + 输入文字微缩归位 → 状态行淡入 → 定格（末端 tl.set 占满 data-duration 防黑帧）。
- 标题高亮实现：titleAccent 作为 titleCn 的子串拆分三段渲染，找不到时自动附加在后，任意文案不破版。
