# 照片取色演示卡

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：荧光绿口播包装族——近黑蓝底 `#0A0D12`，卡片填充 `#12161C`，圆角 16px；主色 `#10B981`，发光高亮 `#34D399`，辅助灰 `#9CA3AF`。全片无橙色、无琥珀色。
- 布局：顶部居中标题（白色粗体 + 绿色高亮词带下划线光条）→ 左侧圆角照片卡（imgPhoto 图片槽，留空时用四张色卡颜色生成 CSS 渐变抽象画占位）→ 照片下方 4 个色卡小方块（swatch2 带绿色描边光环表示"被选中"）+ 灰色说明 → 中间虚线连接左右（线上 3 个小圆点缓慢漂移）→ 右侧 iPhone 样机（绿描边发光，屏幕 CSS 假 UI 的主色用 swatch2 染色，表示"取色生成"）。
- 字体：标题/假 UI 数字标签 = MiSans SemiBold；灰色说明 = MEBHeiHeiTi。仅这两款字体，硬链接自 templates 根目录。
- 标题高亮实现：titleAccent 作为 titleCn 的子串拆分三段渲染，高亮词不在标题中时自动附加在句尾，任意文案不破版。
- 动画：标题淡入 → 左卡滑入 + 色卡 back.out stagger → 说明淡入 → 虚线宽度揭示画出 → 圆点淡入并有限次 yoyo 漂移（repeat 3，演完回原点）→ 手机右滑入 + 假 UI stagger → 定格。时间线末端 tl.set 补齐到 data-duration 防黑帧。
- 素材槽：imgPhoto（image 变量），留空画面仍完整。
