# 霓虹应用双Tab

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：暗夜霓虹（荧光绿口播包装族）——近黑蓝底 `#0A0D12`，荧光绿 `#10B981` 主色 + `#34D399` 发光高亮，卡片填充 `#12161C`、16px 圆角、1px 主色描边 + 外发光；灰辅助字 `#9CA3AF`。纯绿色系，无琥珀橙。
- 构图：顶部标题组（英文小标签·主色大写加字距 → 中文大标题·`titleAccent` 子串染绿带下划线 → 灰色副标题）→ 中央两个并排 Tab 按钮（深色圆角，彩点 + 白色粗体主标签 + 灰色副标签）→ 下方说明字。
- 状态：Tab 激活 = 绿描边 + 外发光 + 绿点亮 + 内容全亮；未激活 = 灰描边 + 灰点 + 内容 45% 透明度。初始 Tab1 激活，t≈2.2s 激活态切换到 Tab2，切换时 Tab2 带马克笔横扫闪光（系列签名动作），说明字同步淡入。
- 字体：英文标签/中文标题/Tab 主标签 = MiSans SemiBold；灰副标题/Tab 副标签/说明字 = MEBHeiHeiTi（@font-face 带 font-weight: 100 1000）。
- 动画：标题组依次淡入 → 双 Tab 上浮入场 → 2.2s 激活态切换（描边/发光/透明度/圆点颜色 0.5s 过渡）→ 横扫闪光 → 说明字淡入 → 定格，时间线末端 tl.set() 占满 data-duration 防黑帧。
