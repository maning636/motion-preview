# 关系符大卡（cream-relation-symbol）

认知号「老马反收割」生产线模板，复刻 V3「A ≠ B / A → B」关系符大卡的绿色化版本。

- 底：奶油纸面 `#F5F0E6` + 10px Ink 外框。
- 构图：左 Paper 短句卡 + 中央超大关系符号 + 右 Paper 短句卡；符号 400px（按字符数自适应）是视觉主角，坐 Paper 圆盘 + 硬投影底座上。
- 强调：品牌绿 `#22c55e`（变量 `accent`），只给符号、角标和胶带。
- 动效：左右卡从两侧弹入 → 圆盘与符号 elastic 弹出 → 符号一次 1.07 脉冲锁定 → 底部灰色口播字幕；约 2.2s 演完定格，`duration` 变量控制总时长。
- 适用：`叙事能力 ≠ 讲故事`、`只是被看到 → 被感受到` 这类一句一卡的认知纠偏节拍。
- 字体：中文 Noto Sans SC 900；角标 Fredoka。禁用橙色、渐变、发光、模糊阴影。
