# 荧光绿问题三卡

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：荧光绿口播包装族——近黑蓝底 `#0A0D12`，卡片 `#12161C` + 1px 主色描边 + `rgba(16,185,129,...)` 外发光，圆角 16px。
- 配色：主色 `#10B981`（编号/英文标签/短横线/bullet 圆点），发光高亮 `#34D399`，语义红 `#EF4444` 仅用于卡片右上角圆圈 X；白色粗体中文标题，灰色 `#9CA3AF` bullet 细节行。禁用琥珀橙。
- 字体：中文标题/编号/英文标签 = MiSans SemiBold；bullet 细节行 = MEBHeiHeiTi（@font-face 带 font-weight: 100 1000）。
- 布局：左上标题组（英文小标签带短横线 + 中文大标题），下方三卡横排（500×560，间距 60，左边距 150）。
- 动画：递进构建——0.4s 标题入 → 0.7s 卡1 入 → 1.9s 卡2 入+卡1 bullets 现 → 3.1s 卡3 入+卡2 bullets 现 → 4.3s 卡3 bullets 现 → 定格。
- 卡3 细节行默认为空（留空自动隐藏），需要时通过 c3B1/c3B2 变量填入。
