# 霓虹浮动标签卡

overlay 浮动标签卡（压实拍用），全屏基底上四角浮动要点卡。按 TEMPLATE-INGEST-STANDARD §2.5：时长 duration 变量化，动效演完定格最后一帧。

- 风格：荧光绿口播包装族——近黑蓝底 `#0A0D12`，卡片 `#12161C` + 1px 主色 `#10B981` 描边 + `rgba(16,185,129,...)` 外发光，圆角 16px；发光高亮 `#34D399`（英文标签短横线与辉光）；白色粗体中文大字。
- 基底：图片槽 `imgBg` 有图则 `object-fit:cover` 铺满 + 55% 黑色压暗层；留空则深黑底 + 径向暗角。
- 卡位：左上 / 左下 / 右上 / 右下四个浮动卡（`c1`–`c4`），每卡 = 英文小标签（主色、全大写、加字距、前置发光短横线）+ 中文大字（max-width 自然换行为两行，禁 `<br>`）；`cNEn` 与 `cNText` 均空则该卡不显示（`c4` 默认空）。
- 字体：中文大字 / 英文标签 = MiSans SemiBold；MEBHeiHeiTi 兜底（`@font-face` 带 `font-weight: 100 1000`）。
- 动画：各卡从各自侧方（左列从左、右列从右）stagger 滑入 → 定格，无收尾出场动画。
- 禁用：琥珀橙（旧版 neon-numbered-cards 配色）；语义红 `#EF4444` 仅限 X/错误场景，本模板未用。
