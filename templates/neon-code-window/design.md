# 霓虹代码窗口卡

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：暗夜霓虹（荧光绿口播包装族）——近黑蓝底 `#0A0D12`，荧光绿 `#10B981` 主色 + `#34D399` 发光高亮做描边/英文小字标签/代码关键字与外发光，白色粗体中文标题，灰色 `#9CA3AF` 辅助。
- 构图：左侧标题组（英文小标签 + 中文标题，titleAccent 命中子串染绿带下划线辉光）；右侧 macOS 风格代码窗口（`#0D1117` 深底、三点标题栏 + 窗口名、1px 绿描边 + 外发光）。
- 代码区：5 行，行号灰 + 简易着色——关键字/字符串 = `#34D399` 绿，注释 = `#9CA3AF` 灰，其余 = 白（仅绿/白/灰三色，无橙）。
- 字体：英文标签/中文标题 = MiSans SemiBold；窗口名/行号/代码正文 = MEBHeiHeiTi。
- 动画：标题组淡入上移 → 窗口右滑入 → 代码行 cascade stagger 逐行淡入 → 定格；时间线末端 tl.set 占满 duration 防黑帧。
- 禁用：琥珀橙、第三方字体、`<br>` 强制换行、repeat:-1。
