# 冰山图视觉规范

## 方向

左侧冰山：水面之上的小三角为可见部分，水面之下的大三角为隐藏部分；右侧文字块解释两者，适合表达显性 UI 与隐性机制的比例悬殊。

## Palette

- Background: `#12100E`
- Foreground: `#F4EFE7`
- Accent: `#00FF00`
- Tip: `#00FF00`
- Body: `rgba(244,239,231,0.08)`
- Waterline: `rgba(244,239,231,0.4)`

## Typography

- 标题：`IBM Plex Mono` 700，64px
- 侧标题：28px，700
- 侧描述：20px，opacity 0.55
- 比例标注：18px，opacity 0.4

## Layout

- 标题区 + 左右分栏
- 左侧冰山图形，右侧上下两个文字块
- 水线贯穿冰山中部

## Motion

- 标题入场
- 水线从左到右绘制
- 水面之上三角升起
- 水面之下三角降下
- 右侧文字块依次滑入
- 结束前整体上移淡出

## Avoid

- 不使用渐变、阴影、3D
- 不添加波浪等装饰
