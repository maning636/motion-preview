# 霓虹步骤点线卡

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：暗夜霓虹（荧光绿口播包装族）——近黑蓝底 `#0A0D12`，荧光绿 `#10B981` 主色 + `#34D399` 发光高亮做圆圈描边/连线/英文小字与外发光，白色粗体中文数字与标签，注释灰 `#9CA3AF`。
- 主色由 `accentColor`（color 变量，默认 `#10B981`）驱动：JS 解析后重写 `--acc` 系列 CSS 变量（含各透明度衍生值）；自定义主色时发光高亮自动向白色混合 35% 推导，默认主色固定对应 `#34D399`。
- 字体：数字/步骤标签/英文小字 = MiSans SemiBold；灰色注释 = MEBHeiHeiTi（@font-face 带 `font-weight: 100 1000`）。
- 布局：中央横排 3 步——128px 绿色描边圆圈（微发光填充）内白色数字 1/2/3，圈下白色中文标签；圆圈之间 172px 绿色发光横线连接；顶部英文小标签 STEP BY STEP（主色全大写加字距），底部一行灰色注释。数字为固定步骤序号，不做变量。
- 动画：递进构建——英文标签淡入 → 圈1 弹入（back.out）→ 线1 从左向右画出（scaleX，origin left）→ 圈2 → 线2 → 圈3 → 注释淡入上移 → 定格，时间线末端 `tl.set()` 占满总时长防黑帧。
- 连线/圆圈均用 HTML div（border-radius / scaleX），避免 SVG transform 的 svgOrigin 坑。
- 禁用：琥珀橙、`<br>` 强制换行、repeat:-1。
