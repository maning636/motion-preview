# 霓虹正误对比条

按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。

- 风格：荧光绿口播包装族——近黑蓝底 `#0A0D12`，卡片填充 `#12161C`，圆角 16px；主色 `#10B981`，发光高亮 `#34D399`，语义红 `#EF4444` 仅用于 ✗/否定，辅助灰 `#9CA3AF`。
- 布局：顶部居中标题（白色粗体 + 绿色高亮词带下划线光条）→ 上条「✓ 你要的」绿色描边发光条（内嵌绿色实心 chip + 灰色描边 chip）→ 下条「✗ 常见回答」红/灰描边条（灰字 + 删除线表否定）→ 条下灰色注释。
- 字体：标题/chip/条内文字 = MiSans SemiBold；灰色注释 = MEBHeiHeiTi。
- 标题高亮实现：titleAccent 作为 title 的子串拆分三段渲染，高亮词不在标题中时自动附加在后，任意文案不破版。
- 动画：标题淡入上移 → 好条（标签+条）左滑入 → 坏条右滑入 → 注释淡入 → 定格。禁用琥珀橙，无橙色元素。
- 图标为模板内置 SVG（绿色勾圆 / 红叉圆），无图片素材槽。
